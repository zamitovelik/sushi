# Фотографии блюд

Положите файл сюда и укажите путь в `lib/data/menu.ts` у нужной позиции:

```ts
{
  id: "roll-philadelphia",
  // ...
  photo: "/menu/roll-philadelphia.jpg",
}
```

Пока `photo` не задан, карточка рисует процедурную SVG-иллюстрацию —
подставлять фото можно по одному, ничего не ломая.

Требования: соотношение примерно 4:3, ширина от 800 px, формат jpg или webp.
Файлы отдаются как статика Next.js, оптимизацию делает `next/image`.
